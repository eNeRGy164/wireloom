# Wire wrapper oracle sources

These RTI sources were generated from the corresponding IDL wrapper in
`tests/Wireloom.Dds.Generator.WireCompatibility/IdlWrappers/`. Each case
manifest records the RTI generator version, wrapper and included input hashes,
and hashes for every retained generated source. The original corpus captures
under `features/` remain unchanged.

The wire runner consumes these checked-in files and does not run `rtiddsgen`.
