# RTI oracle class library

This directory mirrors the central corpus IDL tree and contains the current C#
oracle classes generated by RTI Connext DDS 7.7.0 / rtiddsgen 4.7.0. The
`unknown/` subtree may contain generated evidence for neutral probes; these
sources are not used as managed-generator compliance expectations until the
probe is classified.

These sources are generated reference output from the corpus IDL. They are not
relicensed under the repository's MIT License, and Wireloom does not claim
ownership of RTI material. Retain all original file-level notices and capture
provenance. Rejected cases have an empty case
directory and remain represented in the
[version manifest](../../manifest.json) with their classification.
