# RTI oracle class library

This directory mirrors the central corpus IDL tree and contains the current C#
oracle classes generated by RTI Connext DDS 7.7.0 / rtiddsgen 4.7.0. The
`unknown/` subtree may contain generated evidence for neutral probes; these
sources are not used as managed-generator compliance expectations until the
probe is classified.

sources. They are third-party reference material, provided as-is for
compatibility testing, and remain subject to any applicable RTI rights and
terms. Do not redistribute them except as permitted by the applicable RTI
license; retain all file-level notices. Rejected cases have an empty case
directory and remain represented in manifest.json with their classification.
