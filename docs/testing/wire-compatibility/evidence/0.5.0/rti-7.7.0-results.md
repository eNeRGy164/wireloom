## Case-specific generation and peer scope

- **05-array-of-sequences-idl**: RTI C++ uses the default generation flags. C149 with SequenceArrayMapping=Idl. The duplicate IDL has the same declarations as C018; live DDS results apply only to the recorded fixtures and exact runtime version. [Workaround guide](https://github.com/eNeRGy164/wireloom/blob/01f66fe07a9065751430c3b71bbc72a2a7a4ad0e/tests/Wireloom.Dds.Generator.WireCompatibility/WORKAROUNDS.md)
  Wireloom configuration: `{"idl":"idl/features/05-array-of-sequences-idl.idl","sequenceArrayMapping":"Idl"}`. Input and generated-source SHA-256 hashes are in the JSON evidence.
  Known exception for **RTI C#**: The direct-form RTI C# binding flattens arrays of sequences and describes a different type.
- **06-aggregates**: RTI C++ generation adds `-unboundedSupport`. Recursive-structure support is experimental in RTI C++ and requires -unboundedSupport. Direct self-recursive sequence members are exercised by a focused fixture in the standard wire matrix. [Workaround W011](https://github.com/eNeRGy164/wireloom/blob/01f66fe07a9065751430c3b71bbc72a2a7a4ad0e/tests/Wireloom.Dds.Generator.WireCompatibility/WORKAROUNDS.md#w011), [Workaround W012](https://github.com/eNeRGy164/wireloom/blob/01f66fe07a9065751430c3b71bbc72a2a7a4ad0e/tests/Wireloom.Dds.Generator.WireCompatibility/WORKAROUNDS.md#w012)
- **07-union-octet**: RTI C++ uses the default generation flags.  [Workaround guide](https://github.com/eNeRGy164/wireloom/blob/01f66fe07a9065751430c3b71bbc72a2a7a4ad0e/tests/Wireloom.Dds.Generator.WireCompatibility/WORKAROUNDS.md)
  Known exception for **RTI C#**: RTI 7.7.0 generated C# does not compile for the octet discriminator (CS0246); the known-good RTI 7.3.1 C# peer remains enabled.
